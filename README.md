# CryptoDATEX — Профессиональный аналитический терминал для крипто-фьючерсов и золота

**CryptoDATEX** — это высокопроизводительный локальный веб-терминал для трейдинга и глубокого анализа фьючерсов Binance Futures (USDT-M) и золота (PAXG/USDT). Терминал объединяет нативный график Lightweight Charts, тепловые карты ликвидаций, профили объема HVN, индикаторы на машинном обучении (kNN), многоканальные алерты со встроенным звуковым синтезатором, адаптивный календарь макроданных с нулевой задержкой и гибкую систему уровней доступа (Free / PRO).

---

## 🚀 Основные возможности

### 1. Крипто-фьючерсы Binance (Crypto)
* **Любые контракты Binance Futures**: поиск и выбор любого активного USDT-M перпетуал контракта на лету (BTC, ETH, SOL, BNB, DOGE, PEPE, SUI и др.).
* **Оптимизированные внутридневные таймфреймы**: `5m`, `15m`, `30m`, `1h`, `4h`.
* **Реалтайм стриминг**: прямое WebSocket-подключение к Binance Futures (`@kline` + `@aggTrade`) с нулевой задержкой.
* **Матрица корреляций**: динамический расчет топ-10 скоррелированных монет на 1-часовом таймфрейме.

### 2. Аналитика Золота (Gold / XAUUSD Proxy)
* **Котировки золота**: спот-прокси `PAXGUSDT` через Binance Futures.
* **Таймфреймы**: `15m`, `1H`, `4H`, `1D`.
* **Специализированные индикаторы**: линейный регрессионный канал (LRC), пересечение скользящих средних, Parabolic SAR, Ultimate Oscillator (7/14/28) и Linear Regression Slope.

### 3. Индикаторы и Аналитика (10+ алгоритмов)
* **WTMO**: WaveTrend Momentum Oscillator.
* **MLMI**: Machine Learning Momentum Index на базе алгоритма k-ближайших соседей (kNN).
* **RSI & ADX**: Relative Strength Index и Average Directional Index (+ DM+/DM-).
* **MFI, CCI, W%R, UO, CMF**: Money Flow Index, Commodity Channel Index, Williams %R, Ultimate Oscillator, Chaikin Money Flow.
* **CVD & DEPTH**: Кумулятивная дельта объема и стаканная ликвидность на глубине ±2%, ±5%, ±10%.
* **Volume Spikes**: Цветовая подсветка аномальных объемов по PineScript-алгоритму VOLUDE.

### 4. Зоны ликвидности и профили (Liquidation & HVN Profiles)
* **Подтвержденные зоны HVN**: фильтрация уровней высокой плотности объема, подтвержденных на 3+ движениях ZigZag.
* **Тепловая карта ликвидаций**: кластеры уровней ликвидаций позиций лонг/шорт.
* **Профили движений ZigZag**: расчет Value Area (70%) и Point of Control (POC) для каждого ценового импульса.

### 5. Система алертов и аудио-синтезатор (Alarms & Web Audio Synthesizer)
* **Гибкие триггеры**:
  * Цена: Пересечение снизу вверх, пересечение сверху вниз, выше уровня, ниже уровня.
  * Индикаторы: RSI перекупленность (>70), RSI перепроданность (<30), ADX сильный тренд (>25).
  * Объем: Всплески объема 2x, 3x, 5x.
* **Встроенный аудио-синтезатор**: генерация звуков на лету через браузерный Web Audio API (без скачивания файлов, работает оффлайн):
  * `Radar Ping`, `Double Chime`, `High Siren`, `Cash Ding`, `Sub Bass Pulse`, `Digital Pager`, `Sci-Fi Laser`, `Urgent Pulse`.
* **Многоканальная доставка**: мгновенный звук в браузере + отправка в Telegram-бот + отправка на Email.

### 6. Макроэкономический календарь с нулевой задержкой
* **Адаптивный быстрый опрос**: при приближении времени публикации макроэкономических показателей (от -5 минут до +1 минуты) сервер переходит в режим 3-секундного опроса, гарантируя получение фактических данных (`Actual`) в первую минуту публикации (11:00 / 11:01).
* **Связка с криптовалютами**: контекстные подсказки реакции рынка на основе базы знаний `macro_meta.json`.

### 7. Система доступа Free / PRO (Seed Phrase Unlock)
* **Free Tier** (по умолчанию): доступны базовые инструменты (RSI, ADX, подтвержденные HVN-зоны, поиск монет).
* **PRO Tier**: открывает полный доступ ко всем индикаторам, стакану DEPTH, тепловым картам ликвидаций и профилям волн по вводу секретной сид-фразы (например: `crypto datex pro alpha`).

## 🛠️ Установка и запуск

### Быстрый запуск (Windows)
1. Дважды кликните по файлу **`start.bat`**.
2. Скрипт автоматически проверит виртуальное окружение `.venv`, установит зависимости из `requirements.txt`, запустит сервер на порту `5050` и откроет браузер.

### Ручной запуск (Windows / Linux / macOS)
```bash
# 1. Создание виртуального окружения
python -m venv .venv

# 2. Активация окружения
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Запуск сервера
python server.py
```
После запуска откройте в браузере: **`http://127.0.0.1:5050/`**

## ⚙️ Настройка уведомлений

### 1. Telegram
Скопируйте `telegram_config.example.json` в `telegram_config.json` (или настройте через модальное окно на сайте):
```json
{
  "enabled": true,
  "token": "ВАШ_ТОКЕН_БОТА",
  "chat_id": "ВАШ_CHAT_ID",
  "symbol": "BTCUSDT",
  "notify_volume": true,
  "notify_macro": true,
  "macro_lead_minutes": 15
}
```

### 2. Email (SMTP)
Скопируйте `email_config.example.json` в `email_config.json` (или настройте через модальное окно `✉️ Email`):
```json
{
  "enabled": true,
  "smtp_host": "smtp.gmail.com",
  "smtp_port": 587,
  "use_tls": true,
  "user": "your_email@gmail.com",
  "password": "your_app_password",
  "to": "recipient@example.com",
  "notify_volume": true,
  "notify_macro": true,
  "notify_macro_actual": true,
  "notify_alarms": true
}
```
